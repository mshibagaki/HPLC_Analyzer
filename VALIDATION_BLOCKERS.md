# External blockers and deferred physical validation

Updated: 2026-09-04

This file records work that source changes and automated CI cannot complete alone. An unavailable physical or external gate is `BLOCKED — evidence required`; it is never treated as passed or silently marked not applicable. Release execution remains governed by `.github/RELEASE_PROCESS.md` and `.github/RELEASE_CHECKLIST.md`.

Version context: latest published Stable is `1.2.4`; current main development line is `1.3.0-dev.1`. No `1.3.0` tag or Release exists yet.

- Issue #238 fixed saturated-peak correction on the EMG model, which had been returning approximately the clipping ceiling instead of the reconstructed peak. `emg_profile` normalizes by the maximum of whatever samples it is given, and the correction deliberately excludes the clipped apex samples from the fit, so the least-squares amplitude found on the remaining samples meant the height at the edge of that exclusion, not the model's true peak. A one-time post-fit rescale onto a range that contains the true apex — evaluated once after the search converges, not inside it, per the workflow document's explicit warning that doing so cost over two minutes — fixes this. Two kinds of evidence support it: an isolated test supplies the correction the exact (center, sigma, tau) a real fit only approximates, and confirms the rescale recovers the true amplitude to within 1e-6 in well under a second, showing the correction itself is an exact algebraic identity, not an approximation. An end-to-end test then fits a realistic, densely sampled (2,401-point) synthetic EMG peak clipped to 90/70/50/35% of its true height and measures the full pipeline: height recovery improved from -11.6%/-30.0%/-50.3%/-65.1% before the fix to -3.15%/-5.71%/-0.92%/-0.22% after, and area recovery from -9.5%/-30.0%/-50.7%/-65.1% to -0.81%/-2.36%/-0.48%/-0.13%, all compared on the same synthetic data before and after this change. The residual error is shape (sigma/tau) recovery by the existing coarse-grid search once the most informative apex samples are excluded, not the amplitude correction, which the isolated test shows is exact. An ordinary (unsaturated) EMG fit's height moved by about -1.5%, and the Gaussian path — analytically normalized regardless of which samples it sees — is untouched by construction (the correction only runs when `tau is not None`) and its own existing regression test still passes unchanged. All 368 tests pass in the fixed Windows 11/PySide6 environment (Python 3.11.9 x64, PySide6 6.8.3, Matplotlib 3.10.1, NumPy 2.2.3, PyQtGraph 0.13.7); Python 3.8.10 x86 syntax compilation of the changed files passed; Level 2 source contracts and the Windows 7 offline manifest/wheelhouse check passed. **The new end-to-end regression test alone takes about 40 seconds on this development machine, because EMG's `math.erfc` evaluation is a pure-Python loop run tens of millions of times by the existing (pre-#238) coarse-plus-refinement grid search — a cost this fix did not introduce and did not measurably change (patched and unpatched runs of the same scenario differed by under one second).** `tests.test_core` is part of the Windows 7 physical build's test batch (Issue #244), so that machine will run this module too; its older CPU is expected to take longer than this measurement, proportionally, not categorically — this was not re-measured on physical Windows 7 hardware. No project schema, dependency pin, or offline-build input changed, and no new dependency was introduced.
